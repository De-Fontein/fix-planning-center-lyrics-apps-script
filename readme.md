# Fix Lyrics

A Google Apps Script that automatically fixes and validates song lyrics formatting on a schedule. Ensures sections are properly structured for presentation without issues.

## Installation

1. Open your Google Apps Script project
2. Copy the script code into the editor
3. Setup the Planning Center Personal Access Token in the Script Properties
4. Set up a time-driven trigger to run daily

## Usage

The script runs automatically on schedule to:
- Fix common issues in lyrics
- Detect section headers and format them consistently
- Remove duplicate sections and number unique ones of the same type
